# FlyFood - Roteamento de Drones (PISI2)

## Descrição

Projeto interdisciplinar que implementa um algoritmo de roteamento para drones de entrega.

## Integrantes do Grupo

- **Cauã** - Estrutura base e leitura de arquivos
- **Caio** - Validação de dados
- **Carlos** - Cálculo de distâncias
- **Samuel** - Algoritmo de roteamento

## Como Executar

```bash
cd src
python main.py
```

## Estrutura do Projeto

- `src/models/` - Classes de dados (Matriz)
- `src/utils/` - Funções utilitárias
- `src/algoritmo/` - Implementação do algoritmo
- `input/` - Arquivos de entrada
- `tests/` - Testes automatizados
